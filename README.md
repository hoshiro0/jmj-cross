# Starletters ✦

A public anonymous love-letter website.

## Features

- Public anonymous letters
- Search letters by recipient
- Optional sender name
- Optional Spotify links
- Newest letters first
- Astronomy-inspired design
- Supabase database
- GitHub Pages hosting

## Stack

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Important

The browser uses a Supabase Publishable Key.

Never put a Supabase Secret Key or service_role key in this repository.

Database security is handled through Supabase Row Level Security.
